## 一、明军北伐前的南方整合

| 时间 | 事件 | 地理与结构意义 |
|---|---|---|
| 1352年 | 朱元璋参加红巾军 | 元末地方秩序崩解，为区域军事集团兴起创造空间 |
| 1356年 | 朱元璋占领集庆，改为应天府 | 获得长江下游战略基地，可连接江淮、江南与沿海 |
| 1360—1363年 | 与陈友谅争夺长江中游 | 争夺的不只是城市，而是长江航运与湖区水军体系 |
| 1363年 | 鄱阳湖之战 | 陈友谅集团失败，朱元璋取得长江中游主动权 |
| 1364—1367年 | 继续经营江西、湖广、江浙 | 将区域胜利转化为财政、兵员与粮运能力 |
| 1366—1367年 | 围攻平江，张士诚政权灭亡 | 控制苏州及江南财赋区，北伐的经济基础成熟 |
| 1367年 | 方国珍等东南沿海势力归降或被平定 | 稳定海岸与后方，减少北伐时的侧翼风险 |

## 二、明军北伐：由江淮到大都

| 时间 | 事件 | 主要节点 | 历史地理解释 |
|---|---|---|---|
| 1367年冬 | 徐达任征虏大将军，常遇春任副将军，率军北进 | 应天、淮安、徐州方向 | 依托长江与江淮粮运，不直接孤军深入大都 |
| 1367年末 | 攻取沂州、峄州、莒州、密州、海州等地 | 鲁南 | 打开山东门户，稳定由江淮进入齐鲁的通道 |
| 1367年末—1368年初 | 进取益都、济南、东昌、济宁、东平及登莱 | 山东腹地与运河沿线 | 控制大都东南屏障、运河节点和山东粮源 |
| 1368年初 | 朱元璋在应天称帝，建立明朝 | 南京 | 北伐与建国同步，军事扩张获得新的国家名义 |
| 1368年春 | 徐达由济宁进取汴梁 | 济宁、开封 | 沿黄河与中原交通轴转向河南 |
| 1368年春 | 过虎牢关，攻取洛阳及河南多地 | 开封、洛阳 | 掌握中原核心，切断大都与西部力量的联系 |
| 1368年春夏 | 控制潼关 | 潼关 | 封锁关中东出通道，使元廷难获西北支援 |
| 1368年夏 | 明军在临清会师，开陆路、通河道 | 临清 | 临清是运河—卫河体系枢纽，适合步骑与舟师协同 |
| 1368年夏 | 经德州、长芦，控制直沽 | 德州、沧州、天津 | 利用华北东部水陆走廊逼近大都 |
| 1368年夏 | 河西务作战后进抵通州 | 天津武清、北京通州 | 夺取大都东部水陆门户，元廷首都已被孤立 |
| 1368年8月 | 元顺帝北走，徐达进入大都 | 北京 | 王朝中心转移，但北元与西北元军仍未消失 |
| 1368—1370年 | 明军继续进攻山西、陕西、甘肃等地 | 太原、关中、陇右 | 将“占领首都”扩展为对北方交通与区域中心的持续控制 |

## 三、近代北伐前的广州基地

| 时间 | 事件 | 地理与结构意义 |
|---|---|---|
| 1912—1920年代初 | 北洋体系不断分裂，各地军阀混战 | 北京中央权威下降，地方军事集团控制交通与税源 |
| 1924年 | 国民党改组，第一次国共合作形成 | 党组织、军队和群众动员开始结合 |
| 1924年 | 黄埔军校建立 | 广州附近形成新式军官、政治工作与军事训练中心 |
| 1924—1925年 | 广州政权处理商团冲突并进行东征 | 稳定珠江三角洲与粤东，巩固革命基地 |
| 1925—1926年 | 广东基本统一，两广关系重组 | 北伐后方从一座城市扩大为岭南区域基地 |
| 1925—1926年 | 工会、农会、学生与宣传网络扩展 | 交通线之外形成社会动员网络，为军队提供运输、情报和政治支持 |

## 四、国民革命军北伐第一阶段：广州至长江流域

| 时间 | 事件 | 主要节点 | 历史地理解释 |
|---|---|---|---|
| 1926年7月9日 | 国民革命军在广州正式出师 | 广州 | 由岭南安全基地向全国腹地推进 |
| 1926年7—8月 | 北伐军进入湖南 | 韶关、衡阳、长沙 | 越过南岭后沿湘江谷地北进 |
| 1926年8月 | 汀泗桥、贺胜桥战斗 | 湖北咸宁一带 | 武汉南部门户被突破，吴佩孚防线瓦解 |
| 1926年9—10月 | 汉阳、汉口、武昌相继易手 | 武汉三镇 | 控制长江—汉江交汇枢纽，北伐获得全国性中继站 |
| 1926年9月 | 冯玉祥五原誓师并加入国民革命阵营 | 绥远、陕西、河南方向 | 北伐不再只是南方单线推进，北方和西北出现策应力量 |
| 1926年11月 | 北伐军进入九江、南昌 | 鄱阳湖与赣江下游 | 打开江西和长江下游方向，孙传芳主力受挫 |
| 1926年末—1927年初 | 福建、浙江多地易手 | 福州、杭州及东南沿海 | 东路推进威胁上海、南京与长江三角洲 |

## 五、国民革命军北伐第二阶段：长江下游与政治分裂

| 时间 | 事件 | 主要节点 | 历史地理解释 |
|---|---|---|---|
| 1927年1月 | 国民政府重要机构移至武汉 | 武汉 | 长江中游成为革命政治中心，但与东路军事力量关系复杂 |
| 1927年3月21日 | 上海工人第三次武装起义取得成功 | 上海 | 城市社会动员与北伐军军事推进相互配合，租界仍形成特殊空间 |
| 1927年3月24日 | 北伐军进入南京 | 南京 | 取得长江下游政治中心和江北铁路入口 |
| 1927年春 | 上海、南京、武汉形成三大权力节点 | 长江流域 | 北伐控制范围扩大，但政治中心多元化导致内部竞争加剧 |
| 1927年4月以后 | 国共合作破裂，南京与武汉一度对立 | 上海、南京、武汉 | 军事地图扩大，政治联盟却瓦解，说明占领不等于整合 |
| 1927年5—6月 | 宁汉双方分别继续向河南、徐州方向作战 | 郑州、徐州 | 陇海、京汉、津浦交通轴成为新的前线 |
| 1927年下半年 | 国民党内部重组 | 南京、武汉、上海 | 为1928年重新北进创造政治条件，但地方军队仍有独立性 |

## 六、1928年北伐：铁路时代的华北推进

| 时间 | 事件 | 主要节点 | 历史地理解释 |
|---|---|---|---|
| 1928年初 | 南京方面重组北伐军，蒋介石复任总司令 | 南京 | 长江下游财政、港口与铁路体系成为新一轮北伐基地 |
| 1928年4月 | 北伐重新全面展开 | 津浦、京汉、陇海、正太铁路方向 | 多个军事集团沿铁路轴协同，战争呈现明显节点化 |
| 1928年4—5月 | 北伐军由徐州向山东推进 | 徐州、济宁、济南 | 津浦铁路连接南京与华北，山东成为进入北京—天津的南部门户 |
| 1928年5月 | 济南事件 | 济南、胶济铁路 | 国内战争、列强驻军和铁路权益在同一节点冲突 |
| 1928年5月 | 各路军队在河南、山东、山西方向推进 | 郑州、德州、石家庄 | 京汉、津浦、正太等线路形成对北京—天津的多方向压力 |
| 1928年6月3日 | 张作霖撤离北京 | 北京—奉天铁路 | 奉系决定保存关外实力，首都失去主要防守力量 |
| 1928年6月4日 | 皇姑屯事件，张作霖死亡 | 沈阳附近 | 日本关东军直接介入东北权力重组 |
| 1928年6月8日 | 国民革命军及盟军接管北京 | 北京 | 北洋政府统治结束，北京随后改称北平 |
| 1928年6月12日前后 | 天津被接管 | 天津 | 华北港口、铁路与海河枢纽转入南京方面控制 |
| 1928年12月29日 | 东北易帜 | 奉天、吉林、黑龙江、热河 | 张学良接受南京国民政府名义领导，全国实现形式统一 |

## 七、两次北伐的结构性对照

| 观察线 | 明军北伐 | 国民革命军北伐 |
|---|---|---|
| 根据地形成 | 先统一长江中下游 | 先统一广东并整合两广 |
| 核心运输 | 河运、运河、粮船、驿路 | 铁路、轮船、电报、公路与传统运输并用 |
| 关键中继 | 山东、河南、临清 | 武汉、南昌、南京、上海、徐州 |
| 对首都策略 | 先切断山东、河南、西北外援，再进大都 | 先控制长江流域，再沿多条铁路进入华北 |
| 政治手段 | 招降地方守将、接管府库和行政 | 宣传动员、党军制度、工农组织、收编与联盟 |
| 外部力量 | 以元廷和地方元军为主 | 列强、租界、驻军、铁路权益深度介入 |
| 统一结果 | 王朝更替后逐步形成强中央 | 结束北洋政府，形成名义统一但地方军政仍强 |

## 八、读图记忆法

可以把两次北伐各压缩为一条“节点链”：

### 明军北伐

**应天 → 江淮 → 山东 → 汴梁／洛阳 → 潼关 → 临清／德州 → 直沽／通州 → 大都**

记忆重点：**先隔离，后直取；水陆并进；占领后立即接管秩序。**

### 国民革命军北伐

**广州 → 南岭 → 长沙 → 武汉 → 南昌／九江 → 上海／南京 → 徐州／郑州 → 济南／天津 → 北京 → 东北易帜**

记忆重点：**先两湖，后东南；长江转铁路；军事推进伴随政治联盟变化。**

## 九、结论

两次北伐最深层的共同规律，是南方政权先完成内部整合，再把区域资源通过交通网络投射到北方。首都的陷落只是网络重组的象征性高潮，统一的真实深度则取决于军队、财政、行政和地方权力能否被持续整合。

> 地理决定北伐必须经过哪些门槛，交通技术决定通过门槛的速度，政治制度决定越过门槛之后能走多远。
