# 华尔街投资思维大师课
## 第028课：客户集中度与议价权——大客户为什么既能强化护城河，也可能成为单点风险

**课程日期：2026年8月5日**

上一课讲了订单质量。今天继续追问：

> 如果一家公司的订单真实、客户优秀，为什么客户越大，投资风险有时反而越高？

核心在于：

```text
大客户可以验证产品、加快量产并降低获客成本；
也可以压低价格、延长账期、改变路线图，甚至自行开发替代方案。
```

客户集中度本身不是结论。真正重要的是：**谁更难离开谁。**

---

## 一、先分清四种“客户”

分析半导体与AI基础设施公司时，至少要区分：

| 层级 | 含义 | 常见角色 |
|---|---|---|
| 直接客户 | 直接向公司下单并付款 | 分销商、ODM、OEM、云厂商 |
| 终端客户 | 最终部署或使用产品 | Hyperscaler、企业、政府 |
| 渠道客户 | 负责转售、集成或交付 | 分销商、系统集成商 |
| 经济客户 | 最终决定需求和预算的人 | 云资本开支负责人、政府采购方 |

一家公司的直接客户可能很集中，但终端客户较分散；也可能恰好相反。

因此，不能看到“某分销商占收入45%”，就立即断定45%的最终需求来自同一个用户。也不能因为收入经过多个ODM确认，就误以为终端需求已经充分分散。

---

## 二、三个集中度指标

### 1. 最大客户占比

```text
最大客户收入占比
= 最大客户收入 ÷ 总收入
```

它衡量最明显的单点风险。

### 2. 前三或前十大客户占比

这能识别公司是否依赖少数客户群，而不只是一个客户。

### 3. 应收账款集中度

收入已经确认，不代表现金已经收到。若少数客户占据大部分应收账款，客户延期付款会直接影响现金流。

还可以用HHI做更系统的衡量：

```text
客户HHI
= 每个客户收入占比的平方之和
```

客户越集中，HHI越高。但投资结论仍需结合合同、切换成本和议价权。

---

## 三、客户集中为什么可能是好事

大客户并不总是风险。它可能带来五种价值：

1. **需求验证**：全球最严格的客户采用产品，证明技术和可靠性。
2. **规模经济**：大订单帮助摊薄研发、制造、封装和服务成本。
3. **联合开发**：供应商更早进入客户路线图，形成多代产品关系。
4. **信用质量**：大型云厂商和政府通常具有较强付款能力。
5. **生态扩散**：一个标杆客户可以吸引更多客户采用。

真正优秀的集中型业务通常具备：

```text
客户集中
+ 高切换成本
+ 多年合同
+ 多产品渗透
+ 供应商拥有关键知识产权
```

---

## 四、客户集中为什么可能成为陷阱

风险主要来自六个方向：

| 风险 | 可能后果 |
|---|---|
| 价格压力 | 毛利率下降 |
| 延长账期 | 应收账款和现金转换周期恶化 |
| 订单改期或取消 | Backlog无法按时转为收入 |
| 路线图控制 | 供应商研发被单一客户绑定 |
| 自研替代 | 客户把采购转向内部ASIC或其他方案 |
| 下一代失标 | 当前收入不错，但未来项目突然消失 |

最危险的结构是：

```text
高客户集中
+ 可取消采购订单
+ 客户拥有多个替代供应商
+ 产品差异化低
+ 供应商提前承担大量研发与产能成本
```

# 五、NVIDIA：收入高度集中，但平台议价权仍然很强

NVIDIA在2027财年第一季度披露，三家直接客户分别占总收入21%、17%和16%，合计54%；同一季度末，三家直接客户分别占应收账款30%、18%和16%，合计64%。

但“直接客户”可能是ODM、OEM、系统集成商、云服务商或AI模型公司，不能机械等同于最终使用者。NVIDIA也指出，部分大型间接客户通过多个直接渠道购买产品。

NVIDIA的客户集中风险来自：

```text
少数Hyperscaler决定大量AI CapEx；
客户有能力开发TPU或其他ASIC；
大型客户可以要求更好的价格、交付和产能保障。
```

但NVIDIA拥有强反制能力：

```text
CUDA生态
+ GPU架构
+ NVLink与网络
+ 整机系统
+ 快速产品迭代
```

对客户来说，替换的不是一颗芯片，而是一整套软件、开发流程、集群架构和运维体系。

### 估值思维

华尔街通常愿意接受NVIDIA较高的客户集中度，因为平台切换成本和供给稀缺提高了公司议价权。但估值不能只假设客户继续扩大CapEx，还要压力测试：

```text
最大三家客户支出放缓；
客户自研ASIC份额提高；
GPU供给从短缺转为充足；
毛利率是否仍能维持。
```

# 六、Marvell：联合设计形成护城河，也制造项目型单点风险

Marvell在2027财年第一季度披露，一家直接客户占收入16%，一家分销商占收入45%；三家客户合计占应收账款75%。公司还披露，2026财年前十大客户占总收入82%。

45%的分销商占比不等于45%的终端需求来自一个客户，但说明渠道、回款和出货节奏非常集中。

Marvell的Custom Silicon商业模式具有特殊的议价权变化：

```text
项目选择与竞标阶段：客户权力较强；
Tape-out和验证完成后：切换成本迅速提高；
正式量产阶段：双方形成共同依赖；
下一代重新竞标：客户权力再次上升。
```

护城河来自高速SerDes、交换、光互连IP和多年联合开发经验。但一个大型项目延期、缩量或下一代失标，都可能显著改变未来收入。

### 估值思维

不能只把现有AI收入乘上高倍数，还应按项目分层：

| 项目阶段 | 估值确定性 |
|---|---|
| Design win | 较低 |
| 验证完成 | 中等 |
| 正式量产 | 较高 |
| 多代续约 | 最高 |

华尔街容易在景气期把多个项目都按时兑现计入模型；真正的安全边际来自客户数量增加、项目代际延长，以及每股自由现金流同步增长。

---

# 七、Micron：集中度可能上升，但合同质量显著改善

Micron在2026财年第三季度披露，新签战略客户协议采用Take-or-pay结构，包含多年期、具有合同约束力的具体采购量。多数协议采用固定价格，或设有最低和最高价格区间；少数仍随市场定价。

这改变了传统存储行业的议价结构：

```text
过去：客户可以在价格下跌时减少采购或等待现货；
现在：客户用长期承诺换取供应保障和价格可见度；
Micron用部分价格上行空间换取收入和利润稳定性。
```

这种客户集中不一定更危险，因为合同约束力提高了订单含金量。

但代价也很明确：

- 价格上限可能限制极端景气期的利润；
- 大客户可能影响产品组合、技术路线和扩产节奏；
- Micron仍需先投入晶圆厂、先进封装和HBM产能；
- 如果客户需求预测错误，长期合同也可能出现重新谈判压力。

### 估值思维

Micron最重要的变化不是某一季度EPS更高，而是这些协议能否提高**完整周期利润下限**。

华尔街应重新估算：

```text
价格底部时的毛利率；
合同覆盖的产能比例；
最低采购量是否覆盖新增CapEx；
正常化ROIC是否高于过去周期。
```

# 八、Vertiv：客户很大，但关键基础设施提高供应商议价权

Vertiv服务Hyperscaler、Colocation、通信和企业客户。公司披露，2025年末Backlog达到150亿美元，多数被认为是较确定订单，预计在未来12至18个月交付；但订单仍可能被客户取消或改期。

Vertiv还表示，2025年第四季度订单增长在地区、技术和客户之间较为广泛。这意味着需求并非只来自一个项目，但大型AI数据中心客户仍可能占据重要地位。

大型客户的优势是规模大、付款能力强，并可能提前支付项目款；风险则是：

```text
要求定制工程；
控制项目时点；
压缩设备价格；
将多个供应商放在同一竞标中；
一次项目延期影响单季收入。
```

Vertiv的反制能力来自关键任务可靠性、认证、全球服务网络、系统集成能力和有限的行业产能。数据中心电力和散热设备不能轻易更换，停机成本远高于设备采购价。

### 估值思维

Vertiv的客户集中风险应通过以下指标判断，而不是只看Backlog：

```text
前十大客户订单占比；
项目取消和改期率；
预付款占Backlog比例；
大客户项目毛利率；
Backlog转收入和自由现金流的速度。
```

---

# 九、SpaceX：消费订阅分散客户，政府业务集中但战略价值高

SpaceX公开材料显示，截至2026年3月31日，Starlink订阅用户约1,030万。2025年，消费者订阅收入占Connectivity业务收入超过60%；与此同时，大约五分之一的SpaceX总收入来自美国联邦政府机构。

这形成两种完全不同的客户结构：

| 业务 | 客户结构 | 主要风险 |
|---|---|---|
| Starlink消费者 | 数百万分散用户 | ARPU、流失率、网络容量 |
| 企业连接 | 航空、航运、农业等客户 | 合同续约和服务质量 |
| 政府与Starshield | 少数大型机构 | 预算、监管、采购规则 |
| 发射服务 | 商业和政府任务 | 任务时点与合同集中 |

政府客户既是优势也是风险。优势是高认证壁垒、长期项目和战略地位；风险是预算审批、合规要求和政策变化。

SpaceX的独特之处还在于：政府既是客户，也可能是监管者和关键任务合作伙伴。因此，不能只用普通商业客户流失率分析。

### 估值思维

Starlink消费者收入适合订阅模型；政府和发射业务适合合同Backlog与项目利润模型。把两者混在一个收入倍数中，会掩盖客户集中度差异。

# 十、Ayar Labs：合作伙伴很多，不等于付费客户已经分散

Ayar Labs在2026年完成5亿美元Series E融资，并与Wiwynn、Alchip、GUC等合作推进共封装光学；其生态还包括NVIDIA、AMD、GlobalFoundries等战略参与者。

这些合作能够提供技术验证、制造生态和进入Hyperscaler路线图的机会。但对量产前公司来说：

```text
合作伙伴数量
≠ Design-in数量
≠ 量产客户数量
≠ 收入分散度
```

一个锚定Hyperscaler可能极具价值，因为它帮助定义产品、验证可靠性并形成首个量产案例；但也可能让Ayar Labs过度依赖单一客户架构、封装标准和时间表。

### 估值思维

Ayar Labs当前更应该按里程碑估值：

```text
首个付费Design-in
→ 首个量产客户
→ 第二个独立客户
→ 多平台兼容
→ 客户收入占比逐步下降
```

真正的商业护城河，不是“与很多大公司合作”，而是大公司已经难以替换其技术，并愿意持续支付合理价格。

---

## 十一、华尔街共识最容易犯的错误

市场通常会在两个极端之间摆动：

```text
增长期：
大客户采用 = 产品验证 = 提高估值

放缓期：
大客户集中 = 单点风险 = 压低估值
```

两种看法都可能过于简单。

华尔街模型经常低估四件事：

1. 直接客户与终端客户不是一回事；
2. 客户关系在不同产品阶段的议价权会变化；
3. 高集中度可能伴随更高切换成本和更稳定订单；
4. 客户自研能力可能在下一代产品突然改变竞争格局。

---

## 十二、客户集中度压力测试

假设最大客户占收入20%，该客户采购下降30%：

```text
直接收入冲击
= 20% × 30%
= 总收入下降6%
```

但营业利润可能下降更多，因为研发、管理和部分制造成本不会同步减少。

应进一步测试：

```text
客户降价5%会使毛利率下降多少？
客户延长30天付款会占用多少现金？
下一代项目失标会影响几年收入？
客户自研后，公司能否把产品卖给其他客户？
```

---

## 十三、八步客户质量检查法

1. 最大、前三和前十大客户占收入多少？
2. 应收账款是否比收入更加集中？
3. 直接客户、渠道和终端客户分别是谁？
4. 订单是否Take-or-pay，能否取消或改期？
5. 谁拥有定价权、技术IP和产品路线图控制权？
6. 客户切换供应商需要多少时间和成本？
7. 公司是否已进入客户下一代产品？
8. 客户是否正在开发内部替代方案？

可以建立一张表：

| 指标 | 当前值 | 趋势 | 风险判断 |
|---|---:|---|---|
| 最大客户收入占比 |  |  |  |
| 前三客户收入占比 |  |  |  |
| 前十大客户收入占比 |  |  |  |
| 前三客户应收占比 |  |  |  |
| 合同平均期限 |  |  |  |
| 可取消订单比例 |  |  |  |
| 客户专属研发占比 |  |  |  |
| 下一代续约率 |  |  |  |

# 今日核心结论

```text
客户集中度告诉你：收入依赖谁；
议价权告诉你：价值最终归谁；
切换成本告诉你：关系能够持续多久；
合同质量告诉你：承诺能否转化为现金。
```

理想结构是：

```text
少数高质量锚定客户
+ 高切换成本
+ 合同约束力强
+ 多代产品续约
+ 终端需求逐步分散
```

危险结构是：

```text
单一客户占比高
+ 采购订单可随时取消
+ 客户拥有替代供应商或自研能力
+ 供应商提前承担研发和产能成本
```

> **大客户不是天然的护城河，也不是天然的风险。关键是客户离开你更痛，还是你失去客户更痛。**

## 课后练习

选择NVIDIA、Marvell、Micron或Vertiv，找出最近一期最大客户、前三客户和应收账款集中度，并写出：

- 客户为什么选择这家公司；
- 客户更换供应商的真实成本；
- 公司失去客户后的收入与利润冲击；
- 客户自研或压价的可能性；
- 当前估值是否已经反映这种集中风险。
