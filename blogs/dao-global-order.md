# 大道废，有仁义：从《道德经》第十八章看全球秩序、社会制度与文明形态的重构

> **摘要**：我们正处在一个旧秩序仍然存在、却越来越难以产生约束力，新秩序已经萌生、却尚未形成共同规则的时代。《道德经》第十八章并没有简单否定仁义、智慧或忠孝，而是揭示了一条更深的政治规律：当社会必须不断高喊某种价值时，往往说明支撑这种价值的日常结构已经受损。今天世界频繁谈论“基于规则的秩序”“民主安全”“国家韧性”“文明价值”，恰恰反映出全球信任、制度能力和共同生活基础的衰退。真正的问题不是口号是否正确，而是大道为何失效，以及如何重建一种不依赖持续动员和强制维持的秩序。

## 一、第十八章不是反道德，而是诊断秩序失灵

《道德经》第十八章说：

> 大道废，有仁义；智慧出，有大伪；六亲不和，有孝慈；国家昏乱，有忠臣。

这段话最容易被误读为：老子反对仁义、智慧、孝慈和忠臣。其实它讨论的不是这些价值本身，而是它们出现的**历史条件**。

家庭和睦时，人们不必每天证明自己“孝”；政治清明时，官员正常履职，不必以悲壮的“忠臣”形象出现；交易建立在长期信用上时，不需要为每一个细节增加复杂合同；国家彼此承认边界与规则时，也不必反复宣称自己维护秩序。只有当自然关系破裂，原来无须言说的规范才会被包装成口号、身份和运动。

因此，第十八章提供的是一条从根本结构到表面现象的因果链：

**大道失效 → 信任下降 → 规则增殖 → 道德标签强化 → 阵营对立加深 → 社会维持成本上升。**

用这条链观察当代世界，可以看到三个同时发生的重构：全球政治从普遍规则走向阵营化；社会制度从程序治理走向危机治理；文明形态从工业时代的民族国家，转向由平台、算法、资本、身份和地缘政治共同塑造的复合体系。

## 二、全球政治秩序：规则仍在，但共同承认正在消退

冷战结束后的全球化秩序建立在几个基本假设上：主要国家即使价值观不同，也能通过联合国、世界贸易组织、国际金融体系和全球供应链形成有限合作；经济相互依赖会提高冲突成本；共同规则可以把大国竞争限制在一定范围内。

今天，这些机构没有消失，但“共同遵守规则”的前提正在松动。

### 1. 联合国投票很多，约束能力却有限

俄乌战争是最清楚的例子。2022年3月，联合国大会以压倒性多数通过决议，要求俄罗斯停止入侵并撤军；到2025年2月，联合国大会仍在就“乌克兰实现全面、公正和持久和平”表决，但投票结构已更为分化。决议表达了国际社会的规范判断，却无法自行结束战争。[联合国2022年决议记录](https://press.un.org/en/2022/ga12407.doc.htm)；[联合国第十一届紧急特别会议资料](https://www.un.org/en/ga/sessions/emergency11th.shtml)

这正像“国家昏乱，有忠臣”：维护规则的人越需要反复申明规则，越说明规则已经不能仅凭共同承认而生效。问题不在于联合国决议没有价值，而在于价值宣告与实际权力之间的距离越来越大。

与此同时，冲突的社会代价仍在累积。联合国难民署统计，截至2025年底，全球约有1.178亿人被迫流离失所，约占世界人口的1.4%。这个数字把抽象的“大国竞争”还原为普通人的迁徙、家庭分离和生活中断。[UNHCR《Global Trends 2025》](https://www.unhcr.org/global-trends)

### 2. 全球化没有终结，而是被“安全化”

过去，芯片、能源、港口、通信设备和供应链主要被视为经济问题；如今，它们同时被视为国家安全问题。关税、出口管制、产业补贴、友岸外包和关键矿产联盟，正在把市场重新嵌入地缘政治。

世界贸易并没有简单崩溃。WTO数据显示，2025年上半年商品贸易一度因提前进口和AI相关产品需求而增长，但更高关税与政策不确定性使2026年前景明显转弱。IMF的研究也发现，美中贸易紧张推动贸易改道，一些“连接国”短期受益，却在长期面对更高脆弱性。[WTO《Global Trade Outlook 2025》](https://www.wto.org/english/news_e/news25_e/stat_07oct25_e.pdf)；[IMF关于碎片化世界贸易模式的研究](https://www.imf.org/en/publications/wp/issues/2025/06/27/demystifying-trade-patterns-in-a-fragmenting-world-567071)

这不是“去全球化”，而是**有条件的再全球化**：资本和商品仍跨境流动，但越来越沿着安全关系、政治信任和技术标准划出的通道流动。效率不再是唯一尺度，韧性、可控性和阵营忠诚成为新的成本函数。

### 3. “全球南方”不愿只在旧秩序中选边

金砖机制的扩展，反映了另一种变化。巴西担任2025年金砖主席国期间，印度尼西亚成为正式成员，埃及、埃塞俄比亚、伊朗、阿联酋等也进入扩大的合作框架；多个国家则以伙伴国身份参与。它们并不必然拥有统一价值观，也未形成类似欧盟的制度共同体，但共同表达了对全球治理代表性不足的不满。[金砖外长会议官方说明](https://brics.br/en/news/collabs/collaborative-communication/brics-foreign-ministers-reiterate-need-for-changes-in-global-governance)

这意味着未来秩序可能既不是单极，也不是两个严密阵营的简单对抗，而是“多中心、议题化、可变联盟”：一个国家在安全上依赖某一方，在贸易上依赖另一方，在能源、金融或技术标准上又加入第三种组合。

从老子的角度看，危险不只是霸权衰落，而是所有力量都以自己的“仁义”解释世界：每一方都自称维护和平、自由、安全或正义，同时把对方定义为秩序破坏者。当价值语言完全阵营化，“有仁义”就可能滑向“以仁义为兵”。

## 三、社会制度：法律越来越密，治理为什么仍显得无力？

现代社会面对的矛盾是：制度规则比历史上任何时期都细密，但普通人对制度的信任并未同步提高。

### 1. 民主仍有选举，却不一定有共同事实

民主制度依靠的不只是投票，还依靠反对者承认程序、公众接触基本事实、政府接受监督，以及失败者相信下一次仍有公平竞争的机会。当媒体生态碎片化、政治身份变成道德身份后，选举可能不再是解决分歧的机制，而成为确认敌我的仪式。

V-Dem的《2026民主报告》认为，民主倒退已经波及部分传统西方民主国家；与此同时，巴西、波兰等国家也出现民主恢复趋势。这说明当代变化不是“民主必然失败”，也不是“威权必然胜利”，而是制度正在经历持续竞争：它能否纠错，比它如何自我命名更重要。[V-Dem《Democracy Report 2026》](https://www.v-dem.net/publications/democracy-reports/)

“智慧出，有大伪”在数字政治中尤其值得警惕。信息工具越聪明，制造选择性事实、情绪动员和拟真内容的能力也越强。社会并非没有信息，而是信息过剩却缺少共同判断框架。于是，各阵营都有专家、数据和证据，但公共理性反而变得稀缺。

### 2. 技术发展越快，制度补丁越多

欧盟《人工智能法案》于2024年生效，并从2025年至2026年分阶段实施，对禁止性用途、通用人工智能模型、透明度和高风险系统设置不同义务。这是大型政治体试图把技术风险纳入公共规则的真实案例。[欧盟委员会AI Act说明](https://digital-strategy.ec.europa.eu/en/policies/regulatory-framework-ai)

这类立法十分必要，但也体现出一种“追赶式治理”：技术先改变就业、传播、教育和权力结构，制度再通过分类、审计、披露和处罚去修补后果。规则越复杂，通常意味着技术系统与社会价值之间的距离越大。

老子并不会要求现代社会取消法律、把一切交给自发秩序。更合理的启示是：**不要把规则数量误认为治理质量。**好的制度应当降低普通人的理解成本，让权力可追责，让不同群体能够继续共同生活；坏的制度则可能一边增加合规文本，一边让真正有资源的行动者更容易规避责任。

### 3. 福利国家从“普遍承诺”转向“稀缺分配”

人口老龄化、住房紧张、移民融合、医疗成本和产业转型，使许多国家的福利制度从扩张时代进入分配冲突时代。社会成员争论的不再只是税率高低，而是谁有资格被照顾、谁为谁承担成本、谁才属于“我们”。

这与“六亲不和，有孝慈”结构相似：当共同体稳固时，照顾弱者被视为正常责任；当共同体身份破裂时，每一项福利都可能变成对贡献、身份和资格的政治审判。此时，无论左翼强调平等、右翼强调责任，都可能把政策讨论道德化，掩盖住房供给不足、生产率停滞、行政效率低下等结构问题。

## 四、文明形态：从普遍主义走向“技术—国家—文明”复合体

过去两百年的现代文明以民族国家、工业生产、市场交换和普遍权利为基本单位。现在，至少有三种力量在改写这一结构。

第一，**平台获得了准公共权力**。搜索、推荐、社交网络和大模型决定什么信息可见、什么语言被放大、什么行为获得奖励。它们不是传统政府，却在塑造公共空间；不是宗教，却影响价值判断；不是学校，却成为知识入口。

第二，**国家重新回到经济中心**。芯片制造、AI算力、能源转型、国防工业和关键矿产都需要长期资本与政策支持。自由市场没有消失，但市场的边界越来越由国家安全划定。

第三，**文明身份重新政治化**。宗教、历史记忆、语言与族群身份被用来解释国家利益，也被用来抵抗全球化的同质化。文明多样性本来可以提供不同的生活智慧；一旦与国家竞争绑定，则容易变成“我们天然正义、他们本质危险”的宏大叙事。

未来的基本单位因而可能不再只是国家，而是由国家、科技公司、金融网络、文化共同体和跨国规则组成的“文明技术栈”。谁控制算力、标准、支付、能源、数据和叙事，谁就拥有塑造秩序的能力。

## 五、用《道德经》看重构：不是退回无政府，而是减少过度用力

《道德经》不能替代国际法、宪法、社会保障或技术监管。把“无为”理解为政府什么都不做，是另一种误读。无为更接近“不以主观意志强行扭曲复杂系统”，即减少那些制造更大反作用的过度干预。

面对当前重构，第十八章至少提供四条原则。

### 1. 从价值宣言回到行为一致

一个国家若要求对手遵守国际法，也应接受相同规则对自己的盟友适用；一个政府若强调信息安全，也应公开权力如何使用数据；一个平台若宣称连接世界，也应说明算法如何影响公共讨论。秩序的信用来自一致性，而不是口号强度。

### 2. 从消灭差异转向管理相互依赖

大国竞争不会消失，但核安全、气候、传染病、金融稳定、AI风险和全球供应链都无法由单一阵营独自管理。现实目标不应是幻想世界完全一致，而是建立最低限度的护栏：即使互不信任，也能防止误判；即使价值不同，也能保留合作接口。

### 3. 从制度增殖转向恢复制度能力

制度改革不只是再成立一个委员会、再写一份原则或再增加一层审批，而要回答三个朴素问题：谁负责？失败后如何纠正？普通人能否理解并使用？能够稳定兑现有限承诺的制度，比不断宣布宏大目标却无法交付的制度更接近“道”。

### 4. 从道德化敌我转向克制的政治

政治需要价值判断，但如果所有政策分歧都被解释为善恶之争，妥协就会变成背叛，纠错就会变成示弱。克制不是没有立场，而是承认自己的知识有限、力量有边界、行动会产生反作用。这正是“无为”对权力最重要的约束。

## 结语：重构的不是版图，而是人类合作的底层协议

今天的危机并非简单的“西方衰落、东方崛起”，也不是民主与威权、全球化与民族主义之间的一次终局决战。真正发生的是底层协议的变化：谁制定规则，谁承担成本，谁获得尊严，谁控制技术，以及不同文明能否在不相互同化的前提下共同存在。

《道德经》第十八章最深的提醒是：不要被表面的道德声量迷惑。一个时代越频繁谈论仁义、忠诚、秩序和安全，我们越应追问——是什么使日常的信任与合作无法自然发生？

全球秩序的出路，不是再发明一个更响亮的普遍口号，也不是让强者以力量取代规则，而是重建“少言而可信、少扰而能治、不同而能共存”的制度基础。真正稳定的文明，不需要每一天证明自己文明；真正有效的秩序，也不需要每一刻高喊秩序。

当“大道”重新成为人们可以实际体验的公平、可预期与相互克制，“仁义”才不会沦为危机时代的装饰，而会回到它本来应该在的位置：不是替代秩序的口号，而是秩序自然流露的人性。
