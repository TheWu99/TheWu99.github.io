# 华尔街投资思维大师课
## 第029课：供应商集中度与产能控制——没有晶圆厂的公司，为什么仍然可能承担巨大的制造风险

**课程日期：2026年8月6日**

上一课讲了客户集中度与议价权。今天把视角转到利润表的另一端：

> 一家公司即使不拥有晶圆厂，也可能为了确保产能支付巨额预付款、签下长期采购承诺，并承担库存、良率和供应中断风险。

核心问题不是“公司有没有工厂”，而是：

```text
谁控制关键产能？
谁承担需求预测错误？
谁在供应短缺时拥有优先权？
```

---

## 一、什么是供应商集中度

供应商集中度表示公司在原材料、零部件、制造、封装测试、设备或物流环节，对少数伙伴的依赖程度。

常见集中形式包括：

| 类型 | 典型依赖 | 风险 |
|---|---|---|
| 单一制造商 | 特定晶圆代工厂或工艺节点 | 中断后难以切换 |
| 单一设备商 | 光刻、沉积、检测设备 | 扩产和工艺升级被卡住 |
| 单一材料商 | 高纯化学品、气体、基板、激光器 | 缺货直接影响产量 |
| 单一封装路径 | CoWoS、HBM封装、先进基板 | 芯片有晶圆也无法交付 |
| 地域集中 | 台湾、韩国、日本等供应集群 | 地缘政治与自然灾害风险 |

真正的风险不是供应商数量少，而是：

```text
供应商集中度
× 切换时间
× 制造前置期
× 预付款和采购承诺
× 需求波动
```

---

## 二、Fabless为什么不一定“轻资产”

Fabless公司不自建先进晶圆厂，因此固定资产通常低于IDM。但它仍可能通过以下方式承担经济资本：

```text
长期晶圆采购合同
+ 产能预付款
+ 封装与基板保证金
+ 供应商库存承诺
+ 客户需求预测错误造成的库存减值
```

所以应区分：

```text
会计上的轻资产
≠
经济上的低资本风险
```

晶圆厂可能在供应商资产负债表上，但需求风险和现金承诺仍可能留在芯片设计公司身上。

---

## 三、产能控制的四个层级

| 层级 | 做法 | 优点 | 代价 |
|---|---|---|---|
| 1 | 现货或普通采购订单 | 灵活 | 缺货时优先级低 |
| 2 | 长期采购协议 | 提高可见度 | 需求下降时难取消 |
| 3 | 预付款和产能保证金 | 获得优先产能 | 现金被占用，可能减值 |
| 4 | 自建或深度垂直整合 | 控制工艺、质量与节奏 | CapEx、固定成本和执行风险最高 |

没有一种模式天然最好。关键是控制力是否值得付出的资本成本。

# 四、NVIDIA：平台护城河强，但制造承诺已经非常庞大

NVIDIA采用Fabless模式，把主要晶圆制造、封装和系统生产交给外部伙伴。2027财年第一季度，公司收入达到816亿美元，其中数据中心收入752亿美元。

截至2026年4月26日，NVIDIA披露的制造、供应和产能承诺达到1,190亿美元，其中950亿美元预计在本财年剩余时间支付。公司还指出，部分供应前置期曾超过12个月，并持续通过预付款、长期协议和产能承诺锁定未来供应。

这意味着NVIDIA虽然不拥有主要先进晶圆厂，却承担了明显的经济制造风险：

```text
需求预测过低
→ 无法获得足够晶圆和先进封装
→ 错失收入和市场份额

需求预测过高
→ 采购承诺超过真实需求
→ 库存、减值和现金占用增加
```

### 商业模式与护城河

NVIDIA的核心护城河是CUDA、GPU架构、NVLink、网络和整机系统，而不是拥有晶圆厂。其平台定价权产生的高毛利和现金流，使公司有能力提前锁定供应。

### 华尔街共识与估值

市场通常把NVIDIA视为高ROIC的轻资产平台。但当供应承诺规模快速扩大时，估值模型还必须加入：库存风险、平台切换、供应地域集中和客户CapEx放缓的压力测试。

高估值需要证明：

```text
预订产能能够转化为高毛利收入，
而不是转化为过剩库存。
```

# 五、Marvell：晶圆厂不在账上，长期制造承诺却越来越重

Marvell同样采用Fabless模式。2027财年第一季度收入为24.18亿美元，同比增长28%。

截至2026年5月2日，公司对晶圆代工、封装和测试伙伴的无条件采购承诺约27.57亿美元。季后又签署协议，为长期晶圆和基板产能支付总计8.70亿美元保证金。

Marvell还披露，大多数产品在某一时间通常只由一家晶圆厂制造，并针对特定工艺进行设计。若原代工厂中断，把产品迁移到另一家工厂可能需要重新设计、验证和客户认证。

### 商业模式与护城河

Marvell的护城河来自高速SerDes、Custom Silicon、交换、存储和光互连IP，以及与Hyperscaler联合设计形成的切换成本。

但这种模式也带来双向锁定：

```text
客户被Marvell设计锁定；
Marvell也被特定代工、封装和基板路径锁定。
```

### 华尔街共识与估值

华尔街通常关注Design win和未来量产收入，却容易低估制造承诺的现金成本。分析Marvell时，应把预付款、最低采购量和供应商承诺视为准投入资本，并检查：

- 项目是否按时量产；
- 产能保证金是否产生合理回报；
- 客户订单能否覆盖长期采购承诺；
- 每股自由现金流是否真正增加。

# 六、Micron：拥有晶圆厂，也无法摆脱上游单点风险

Micron属于IDM，自己拥有并运营大量内存制造设施。2026财年第三季度收入达到414.56亿美元，强劲价格和产品组合带来很高利润。

但自有制造并不等于完全自主。Micron指出，其生产依赖高纯化学品、硅晶圆、气体、光刻胶、基板和多种第三方服务；部分材料、组件和服务只有少数供应商能够达到标准，有时甚至来自单一来源。对于光刻等关键设备，公司也可能依赖单一设备供应商。

Micron全球工厂网络高度互相依赖，一个工厂、设备商或材料供应商发生中断，可能对多个产品造成放大影响。

### 商业模式与护城河

Micron的护城河来自先进DRAM、HBM和NAND工艺、规模制造、良率管理和客户认证。自有晶圆厂使公司能够控制工艺和成本，但也承担巨额CapEx、折旧和固定成本。

### 华尔街共识与估值

市场容易在景气高峰把制造控制力视为优势，却忽略设备、材料、电力、水和地域集中的风险。

对Micron应使用完整周期估值，并追踪：

```text
新增产能回报率
关键设备交付时间
HBM封装能力
材料与能源成本
供应中断后的恢复时间
```

拥有工厂，只是把供应风险从“晶圆代工”上移到了设备、材料、能源和工艺执行。

# 七、Vertiv：供应链不是背景变量，而是订单兑现能力的一部分

Vertiv销售数据中心电力、热管理、液冷和模块化基础设施。2026年第二季度销售额为32.74亿美元，同比增长24%。公司表示，部分收入时点受到临时供应链拥堵和大型多阶段项目执行的影响。

Vertiv的产品由大量电气、机械、制冷和控制组件组成。即使客户需求和Backlog强劲，只要关键部件、工厂或现场交付能力受限，收入仍可能延期。

### 商业模式与护城河

Vertiv的护城河来自关键任务可靠性、工程设计、全球服务网络和客户认证。其供应链能力本身就是护城河的一部分，因为客户购买的不是单个零件，而是能够按时部署并长期运行的完整系统。

### 华尔街共识与估值

高估值阶段，市场不会只奖励订单增长，还会要求：

```text
供应商扩产
→ 工厂生产
→ 现场交付
→ 客户验收
→ 收入与现金
```

任何环节反复延迟，都会降低Backlog的估值含金量。

# 八、SpaceX：垂直整合提高控制力，也集中内部执行风险

SpaceX把火箭设计、发动机、整机制造、软件、发射运营和Starlink部署进行深度整合。2026年6月的一次Starlink任务中，Falcon 9一级助推器完成了第35次飞行，显示重复使用和运营节奏仍在推进。

垂直整合的优势是：

```text
减少外部协调
缩短设计反馈周期
提高生产与发射节奏控制
把关键技术留在内部
```

但风险并未消失，而是转化为：

```text
内部工厂瓶颈
发动机和卫星量产良率
关键电子元件与材料供应
单一生产基地或测试设施中断
```

### 估值思维

公开供应链数据有限，因此不能仅凭发射次数判断资本效率。更重要的是：单位制造成本、翻修成本、卫星替换CapEx、内部产能利用率和故障恢复能力。

垂直整合只有在提高资产周转率和自由现金流时，才真正创造经济价值。

---

# 九、Ayar Labs：生态越完整，制造链也越复杂

Ayar Labs正在推动共封装光学和Optical I/O进入规模生产。公司在2026年3月完成5亿美元Series E融资，用于加速量产。

其制造生态涉及：

```text
硅光子晶圆制造
+ CMOS和ASIC集成
+ 先进封装
+ 外部激光光源
+ 光纤连接
+ 测试与可靠性验证
```

Ayar Labs已与GlobalFoundries、Lumentum、Alchip、GUC、TSMC生态伙伴及系统厂商合作。多伙伴生态能够降低单一环节缺失的风险，但也增加接口、良率、供应协调和责任划分的复杂度。

### 商业模式与护城河

潜在护城河来自TeraPHY光学引擎、专利、系统架构和先发制造生态。

### 华尔街式估值思维

对早期深科技公司，合作伙伴数量不能直接等同于制造成熟度。真正的验证顺序是：

```text
多来源关键部件
→ 可重复制造良率
→ 可靠性认证
→ 量产成本下降
→ 客户规模订单
```

融资能够延长现金跑道，但只有供应链从展示级进入可重复量产，企业价值才会发生实质跃迁。

## 十、华尔街最容易犯的五个供应链错误

1. 把Fabless自动等同于低资本风险；
2. 只看晶圆产能，不看封装、基板、内存和系统部件；
3. 把长期采购承诺全部视为需求信心，而忽略需求下降时的损失；
4. 认为双供应商就等于可以立即切换；
5. 只计算供应中断造成的收入损失，不计算客户关系和市场份额损失。

---

## 十一、如何把供应风险加入估值

可以建立供应链风险折价：

```text
风险调整后价值
≈ 基础内在价值
－ 中断概率 × 中断损失
－ 过剩采购概率 × 库存与承诺损失
```

压力测试至少包括：

| 情景 | 需要估算 |
|---|---|
| 关键供应商停产一个季度 | 收入、毛利和客户流失 |
| 先进封装短缺 | 可交付系统数量 |
| 需求低于预测20% | 库存、预付款和采购损失 |
| 切换供应商 | 重新设计、验证和量产时间 |
| 地缘政治中断 | 替代产能与物流路径 |

高估值公司若缺少替代供应，就应要求更高安全边际。

## 十二、八步供应商质量检查法

1. 前五大供应商分别控制什么环节？
2. 每个关键产品是否真正拥有第二来源？
3. 切换供应商需要几个月还是几年？
4. 公司已支付多少预付款和产能保证金？
5. 无条件采购承诺占未来收入和现金流多少？
6. 晶圆、封装、基板、内存和系统部件是否同样匹配？
7. 供应商是否有能力把产能优先分配给更大客户？
8. 中断后公司能否保护客户关系和市场份额？

# 今日核心结论

```text
客户集中度回答：谁决定需求；

供应商集中度回答：谁控制交付；

产能承诺回答：谁承担预测错误；

切换时间回答：风险发生后多久才能恢复。
```

理想结构是：

```text
关键技术集中
+ 制造来源适度分散
+ 长期产能与客户订单匹配
+ 预付款获得高回报
+ 中断时存在可执行备份方案
```

危险结构是：

```text
单一制造路径
+ 超长前置期
+ 巨额不可取消承诺
+ 客户订单仍可取消
+ 高估值假设完美交付
```

> 没有晶圆厂，不代表没有制造风险；真正的轻资产，是能够用较少资本控制供应，同时把需求预测错误的损失限制在可承受范围内。

## 课后练习

选择NVIDIA、Marvell、Micron或Vertiv，写出：

- 三个最关键供应环节；
- 每个环节的替代来源与切换时间；
- 公司已承担的采购承诺或预付款；
- 需求下降20%时可能产生的库存和现金损失；
- 当前估值是否已经反映供应链风险。
