# 第十四章　西域历史地理时间轴

- **创建日期**：2026-08-01
- **适用章节**：[第十四章《西域》](../Chapters/Chapter14_西域.md)
- **阅读方法**：本时间轴不只排列事件，也标出每一阶段背后的地理机制：河西后勤、东天山门户、塔里木绿洲网络、天山南北联动、帕米尔出口与水资源约束。

## 一、前汉以前：道路早已存在，国家认知尚未连成整体

| 时间 | 事件与区域 | 历史地理意义 |
|---|---|---|
| 公元前2千纪至前1千纪 | 天山南北、塔里木盆地周缘、河西与中亚之间出现作物、牲畜、金属技术和器物交流 | 说明张骞以前已有区域性道路；后来所谓“丝绸之路”是在既有交通基础上被国家与商贸网络重新组织 |
| 公元前1千纪中后期 | 塔里木盆地边缘形成多个依靠河流与灌溉的绿洲聚落和城邦 | 中央沙漠使人口沿盆地边缘分布，政治空间天然呈现多个节点而非连续平面 |
| 战国至西汉初 | 月氏、塞人、乌孙、匈奴等力量在河西、天山和中亚迁徙竞争 | 草原骑兵集团可以借北疆和河西快速移动，并影响南疆绿洲诸国 |

## 二、汉武帝时期：先打通河西，再进入西域

| 时间 | 事件与区域 | 历史地理意义 |
|---|---|---|
| 前138—前126年 | 张骞第一次出使，经匈奴控制区到达大宛、康居、大月氏、大夏等地 | “凿空”的核心是扩大认知地图：中原王朝首次获得较系统的中亚政治、道路和物产情报 |
| 前127—前119年 | 汉军多次反击匈奴 | 削弱匈奴在河套、河西与西域之间的联动，为西向战略创造条件 |
| 前121年前后 | 霍去病河西之战，汉朝逐步控制河西并设置武威、张掖、酒泉、敦煌等郡 | 河西四郡成为关中通向西域的仓储、移民、驿传和军事基地；没有河西，就没有可持续的西域交通 |
| 前119—前115年 | 张骞第二次出使，重点联络乌孙，并派副使分赴周边诸国 | 汉朝外交从单次探险转为多方向网络，开始同时经营天山北麓与葱岭以西关系 |
| 前115年前后以后 | 汉使频繁往返西域 | 使团、商旅和地方向导共同把零散道路转化为较稳定的官方交通系统 |

## 三、争夺交通节点：楼兰、车师、大宛与屯田

| 时间 | 事件与区域 | 历史地理意义 |
|---|---|---|
| 前108年前后 | 汉军进攻楼兰、车师 | 楼兰扼守罗布泊与塔里木南北道入口；车师控制吐鲁番与跨天山门户，小国因节点位置而具有超出人口规模的战略价值 |
| 前104—前101年 | 汉朝发动大宛战争 | 远征目标除良马外，还涉及使者安全、国家威望与西向交通秩序；胜利提高汉朝在诸国中的影响，但不等于直接郡县统治大宛 |
| 前101年后 | 汉在轮台、渠犁等地屯田，设置使者校尉等机构 | 以本地农业降低远程运粮成本，把季节性军事抵达转为常态驻守和道路维护 |
| 前1世纪前期 | 汉、匈奴反复争夺车师和天山南北通道 | 说明只控制塔里木南缘不足以稳定西域，还必须处理北疆草原力量与东天山山口 |

## 四、西域都护时期：节点、印绶与地方合作的制度化

| 时间 | 事件与区域 | 历史地理意义 |
|---|---|---|
| 前60年 | 匈奴日逐王归汉；汉宣帝设置西域都护，郑吉任首任都护 | 汉朝开始制度化统筹天山南北诸国；都护以乌垒附近为枢纽，联系塔里木北缘、车师与河西交通 |
| 前60年至西汉末 | 都护、屯田官、使者与地方王侯共同维持道路和秩序 | 管辖并非把所有绿洲改成郡县，而是以印绶、册封、驻军、调解和联盟组成分层治理网络 |
| 前36年 | 陈汤、甘延寿远征康居方向，击败郅支单于 | 展示汉朝可借西域节点向葱岭以西实施远程行动，但此类行动仍高度依赖地方兵力和沿途补给 |
| 西汉末至王莽时期 | 朝廷与西域关系恶化，交通和治理体系受损 | 网络型控制一旦失去信誉、赏赐和后勤支持，多个绿洲节点会迅速转向其他力量 |

## 五、东汉重建：班超与低成本联盟网络

| 时间 | 事件与区域 | 历史地理意义 |
|---|---|---|
| 73年 | 班超随军进入西域，开始长期活动 | 东汉以有限中央兵力撬动地方联盟，证明情报、信誉和政治判断可以放大军事资源 |
| 74—76年 | 东汉一度恢复西域都护，后因内地和北方形势撤回部分力量 | 西域政策受核心区财政与边防优先级直接制约 |
| 80—90年代 | 班超联合于阗、疏勒等力量，逐步恢复对塔里木盆地诸国的影响 | 绿洲政治不是简单两强对抗；地方国家会根据安全、贸易与邻国冲突选择联盟 |
| 91年 | 班超任西域都护 | 以疏勒等西部节点为基础，东汉影响扩展至葱岭方向 |
| 97年 | 甘英奉班超命西使，抵达安息西境附近 | 西域网络继续扩大中国对西亚方向的知识，但交通仍由多段地方道路和转译体系组成 |
| 102年 | 班超回到洛阳 | 个人威望难以完全制度化，继任者与中央支持变化会影响网络稳定 |
| 123年 | 东汉设置西域长史等机构 | 在都护制度变化后继续以较轻量的军政体系经营西域 |

## 六、魏晋南北朝：东天山州郡化与多政权并存

| 时间 | 事件与区域 | 历史地理意义 |
|---|---|---|
| 3世纪 | 曹魏、西晋沿用戊己校尉、西域长史等制度 | 吐鲁番和东天山仍是中原政权能够保持联系的近西域基地 |
| 327年前后 | 前凉在高昌设置郡县 | 郡县制度进一步进入吐鲁番盆地；高昌依靠绿洲农业和东天山交通成为稳定中心 |
| 4—6世纪 | 前秦、北凉、高昌诸政权以及柔然、嚈哒等力量先后影响西域 | 中原分裂并未使西域交通停止，反而形成多政治中心、多语言和多宗教并存格局 |
| 5—6世纪 | 龟兹、于阗、高昌佛教文化繁荣，粟特商人活跃 | 西域不仅转运文化，也形成石窟、翻译、音乐和商贸制度等本地创造 |
| 6世纪中后期 | 突厥势力控制天山南北和中亚部分地区 | 草原帝国利用天山北麓高机动网络，对南疆绿洲施加政治和军事影响 |

## 七、唐代前期：先取高昌，再建安西与北庭双中心

| 时间 | 事件与区域 | 历史地理意义 |
|---|---|---|
| 630年 | 伊吾地区归唐，唐置伊州 | 河西与西域之间增加东部州县节点，哈密门户得到制度化控制 |
| 640年 | 唐平高昌，设置西州、安西都护府和庭州 | 唐朝先控制东天山门户，再向塔里木和天山北麓展开；吐鲁番绿洲成为前进基地 |
| 648年前后 | 唐军进入龟兹，安西军政中心逐渐西移 | 龟兹位于塔里木北缘中部，便于统筹焉耆、疏勒、于阗和葱岭方向 |
| 657年 | 苏定方击败西突厥阿史那贺鲁势力 | 唐朝能够进一步组织天山南北及中亚部分羁縻区域，但实际控制仍有强弱层级 |
| 7世纪中后期 | 龟兹、于阗、疏勒、碎叶等构成安西四镇，组合一度调整 | 四镇是军事与交通节点体系，并非四个边界固定的省份 |
| 670—692年 | 唐与吐蕃围绕安西四镇多次争夺 | 吐蕃可由青藏高原北缘和塔里木南道施压，说明西域安全同时受河西、青藏和天山多方向影响 |
| 692年 | 唐恢复安西四镇 | 重建塔里木盆地的军事节点和驿路网络 |
| 702年 | 武则天设置北庭都护府 | 安西重点经营天山以南与葱岭，北庭重点经营天山北麓和草原，形成双中心分区架构 |
| 711年后 | 北庭升为大都护府 | 唐朝通过北庭、安西以及伊州、西州、庭州构成天山南北一体化军政交通体系 |

## 八、唐代转折：不是一场战役，而是中间走廊断裂

| 时间 | 事件与区域 | 历史地理意义 |
|---|---|---|
| 751年 | 怛罗斯之战 | 反映唐、阿拔斯势力和中亚地方集团竞争；其象征意义大，但并未使唐朝立即退出安西 |
| 755年 | 安史之乱爆发 | 唐朝调回西北精锐，核心区危机改变远方战略优先级 |
| 760年代起 | 吐蕃逐步夺取陇右、河西部分地区 | 真正致命的是长安—河西—西域中间补给链被切断，而不只是最西端战场失利 |
| 8世纪后期 | 安西、北庭守军与本土长期失联，部分地区仍沿用唐制和年号 | 远方节点可凭既有制度和地方合作延续一段时间，但缺乏军饷、人员和命令补充后难以持久 |
| 790年前后 | 北庭等地相继失守或转入其他政权控制 | 安西、北庭双中心体系最终因整体交通网络瓦解而退出历史舞台 |

## 九、唐以后至清代：政权更替，绿洲与草原网络继续运行

| 时间 | 事件与区域 | 历史地理意义 |
|---|---|---|
| 9世纪中后期 | 回鹘西迁，形成高昌回鹘等政权 | 回鹘利用吐鲁番、北庭与天山交通重建区域秩序，佛教和突厥语文化发展 |
| 10—11世纪 | 喀喇汗王朝影响喀什、于阗等地 | 伊斯兰文化逐渐在西部和南疆传播，西域宗教与语言格局发生长期变化 |
| 12世纪 | 西辽控制天山南北和中亚部分地区 | 西域再度处于跨中亚帝国网络中，绿洲城市和草原交通并存 |
| 13世纪 | 蒙古帝国及察合台汗国统治西域 | 欧亚驿路体系扩大，人员、技术和商品跨大陆流动加速 |
| 明代 | 明朝经营哈密卫，并与西域诸势力保持册封、贡使和贸易关系 | 哈密仍是河西之外的关键门户，但明朝对更西区域的直接控制有限 |
| 1755—1759年 | 清朝先后平定准噶尔和大小和卓之乱，统一天山南北 | 北疆草原与南疆绿洲被纳入同一军政体系，区域战略再次呈现南北联动 |
| 1762年 | 清设伊犁将军 | 伊犁河谷兼具草原、农业与中亚门户条件，成为统筹天山南北的重要军政中心 |
| 1884年 | 新疆建省 | 从军府体系转向行省治理，加强行政、财政和州县整合，现代新疆政区框架逐步形成 |

## 十、近现代认知与遗产保护

| 时间 | 事件与区域 | 历史地理意义 |
|---|---|---|
| 19世纪末 | 德国地理学家李希霍芬提出并推广“丝绸之路”概念 | 一个近代学术名词后来成为理解古代欧亚交通的常用框架，但容易让人误以为只有一条固定路线 |
| 20世纪以来 | 楼兰、尼雅、高昌、龟兹、北庭等遗址持续调查发掘 | 出土文书、建筑和生态材料不断修正仅凭传世史书形成的认识 |
| 2014年 | “丝绸之路：长安—天山廊道的路网”列入世界遗产名录 | 强调丝路是由城市、驿站、寺院、关隘和多国道路共同组成的网络遗产 |
| 2018年至今 | 卓尔库特古城等西域都护府遗址群持续考古 | 通过地层、建筑、木构和文物研究，进一步讨论乌垒及汉代军政中心的具体地望与性质 |

## 十一、分期总览：每个时代控制的究竟是什么

| 历史阶段 | 核心目标 | 关键节点 | 主要治理方式 | 最脆弱环节 |
|---|---|---|---|---|
| 汉武帝时期 | 削弱匈奴、获得盟友与道路情报 | 河西四郡、楼兰、车师、轮台 | 使者、战争、屯田、外交 | 远程运粮和道路治安 |
| 西汉都护时期 | 统筹诸国与天山南北 | 乌垒、车师、龟兹、于阗、疏勒 | 都护、印绶、地方王侯、屯田 | 中央信誉与匈奴压力 |
| 东汉班超时期 | 低成本恢复影响 | 于阗、疏勒、龟兹等联盟节点 | 外交、地方兵、威慑、长史体系 | 对关键个人和地方合作的依赖 |
| 魏晋南北朝 | 保持东部基地与区域联系 | 高昌、伊吾、龟兹、于阗 | 郡县、地方政权、商贸宗教网络 | 多政权竞争和道路分裂 |
| 唐安西北庭时期 | 建立天山南北双中心与西向军政体系 | 伊州、西州、安西四镇、北庭 | 州县、羁縻、军镇、屯田、驿传 | 河西陇右中间走廊 |
| 清代 | 统一天山南北并建立稳定行政体系 | 伊犁、乌鲁木齐、喀什、各绿洲城镇 | 军府、伯克制调整、州县、建省 | 超长边防、水资源与交通成本 |

## 十二、时间轴结论

西域历史不是一条由“开通”走向“封闭”的直线，而是多个交通网络不断形成、断裂和重组的过程。张骞扩大了认知网络，河西四郡提供后勤网络，西域都护把外交与驻军制度化，班超用地方联盟重建网络，唐朝以安西、北庭建立南北双中心，而安史之乱后真正导致体系衰落的，是核心区与前线之间的河西、陇右链条被切断。

贯穿两千多年历史的共同规律是：

> 西域的有效经营，从不取决于地图上宣称覆盖多大，而取决于雪山水源是否稳定、绿洲节点是否合作、山口与驿路是否安全、地方制度是否可持续，以及核心区能否长期承担后勤成本。
