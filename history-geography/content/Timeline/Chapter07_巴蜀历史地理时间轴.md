# 第七章配套时间轴：巴蜀历史地理

> 本时间轴围绕四川盆地、成都平原、汉中、剑门、重庆与三峡的关系展开。年代较早的古蜀事件存在考古与文献解释差异，应把“确定年代”和“传统叙述”区分开来。

| 时间 | 事件 | 地理意义 |
|---|---|---|
| 约公元前5至前3世纪 | 巴国与蜀国分别发展 | 成都平原与峡江—嘉陵江区域形成不同政治中心和交通网络 |
| 前316年 | 秦灭蜀并控制巴地 | 关中政权取得四川盆地资源区，并进入长江上游体系 |
| 约前256年 | 李冰主持的都江堰工程开始形成 | 岷江水量被导入成都平原，防洪、排沙与灌溉提高区域承载力 |
| 前3世纪后期 | 秦持续经营巴蜀郡县、道路和水利 | 自然盆地逐渐被整合为帝国后方和统一战争资源区 |
| 前206年 | 刘邦受封汉王，进入汉中、巴蜀方向 | 汉中和巴蜀成为被排挤政治集团的安全后方 |
| 前206—前202年 | 刘邦还定三秦并最终建立汉朝 | 说明汉中既是巴蜀北部门户，也是反攻关中的出发台 |
| 东汉末年 | 刘焉、刘璋先后经营益州 | 盆地内部资源支持相对独立的区域政权 |
| 211—214年 | 刘备入蜀并取得成都 | 刘备由流动作战集团转变为拥有稳定腹地的政权 |
| 219年 | 刘备集团取得汉中 | 蜀地北线防御推进至秦岭南侧，并获得北伐前进基地 |
| 221年 | 刘备在成都称帝，建立蜀汉 | 成都平原成为国家行政、财政与人口核心 |
| 263年 | 魏军攻蜀，邓艾经阴平险道进入成都方向 | 非传统路线突破暴露蜀汉多层防御和机动预备不足 |
| 304—347年 | 成汉政权存在 | 四川盆地再次利用外部进入成本与内部资源形成割据 |
| 907—925年 | 前蜀以成都为中心 | 唐末五代分裂中，盆地成为相对独立的政治空间 |
| 934—965年 | 后蜀以成都为中心 | 成都平原继续支撑区域政权，但难以低成本向全国扩张 |
| 8世纪中后期 | 安史之乱中唐玄宗入蜀 | 巴蜀成为帝国危机时保存皇室和政权的后方 |
| 9世纪末 | 唐僖宗入蜀 | 再次显示盆地在北方、中原动乱中的避难功能 |
| 13世纪中期 | 南宋在四川经营山城防御体系 | 防御由单一关口转向沿江、高地和多节点堡寨网络 |
| 1259年 | 蒙古军围攻合州钓鱼城 | 嘉陵江流域山城与区域支援显著提高进攻成本 |
| 明清时期 | 成都、重庆及长江上游城市网络持续发展 | 西部农业中心与东部峡江门户的分工更加稳定 |
| 1937—1945年 | 重庆成为抗战大后方的重要政治与工业中心 | 山地城市、长江交通和内陆纵深获得全国性战略价值 |
| 20世纪后期 | 铁路、公路、水运和航空网络快速扩展 | 蜀道和三峡不再是唯一通道，盆地封闭性明显下降 |
| 2021年以后 | 成渝地区双城经济圈建设持续推进 | 成都的平原腹地与重庆的峡江门户在现代综合交通和产业网络中重新组合 |

## 三条主线

### 1. 从自然潜力到国家能力

成都平原并非仅因气候温暖而富庶。都江堰、渠道维护、人口组织、郡县行政和道路建设共同把自然潜力转化为稳定产出。

### 2. 从单一关口到多层防御

巴蜀安全不能只依靠剑门或三峡。汉中前沿、蜀道节点、成都预备力量、重庆峡江门户和内部山城共同构成更可靠的防御网络。

### 3. 从盆地割据到双城开放

古代盆地适合保存资源，却限制对外投送。现代交通降低山地成本后，成都与重庆的互补价值上升：一个组织平原腹地，一个连接长江与外部通道。
